## 🎯 Cara Claim Mission Reward

### Step 1: Buka Missions Screen

- Tap icon ⭐ di Home screen
- Atau dari Profile → Missions (jika ada)

### Step 2: Lihat Tab Missions

Missions screen memiliki 3 tab:

- **Daily**: Mission harian (reset setiap hari)
- **Weekly**: Mission mingguan (reset setiap Senin)
- **Achievements**: Mission sekali selesai (permanent)

### Step 3: Complete Mission

Mission akan otomatis track progress saat kamu melakukan aktivitas:

- Login → Daily Login mission progress +1
- Baca episode → Daily Read 3 mission progress +1
- Comment → Daily Comment 2 mission progress +1
- Like episode → Daily Like 5 mission progress +1

### Step 4: Claim Reward

Saat mission complete:

1. Mission card akan berubah warna (border hijau)
2. Progress bar penuh (100%)
3. Button "Claim" muncul (warna hijau)
4. Tap button "Claim"
5. Reward masuk (XP + Coins)
6. Status berubah jadi "Claimed"

## ⏰ Reset Schedule

### Daily Missions

- **Reset**: Setiap hari jam 00:00 (midnight)
- **Progress**: Reset ke 0
- **Claimed**: Reset, bisa claim lagi besok

### Weekly Missions

- **Reset**: Setiap Senin jam 00:00
- **Progress**: Reset ke 0
- **Claimed**: Reset, bisa claim lagi minggu depan

### Achievements

- **Reset**: TIDAK PERNAH
- **Once Claimed**: Tidak bisa claim lagi
- **Permanent**: Sekali selesai, selamanya

## 🐛 Troubleshooting

### Mission tidak complete padahal sudah selesai

**Possible Causes**:

1. Progress belum tersimpan
2. Target belum tercapai
3. Cache issue

**Solution**:

1. Pull to refresh di Missions screen
2. Check progress bar (harus 100%)
3. Restart app jika perlu

### Button Claim tidak muncul

**Check**:

1. Progress bar sudah 100%?
2. Status "Complete" atau "In Progress"?
3. Sudah claimed sebelumnya?

**Solution**:

- Jika progress < 100%: Lanjutkan aktivitas
- Jika sudah claimed: Tunggu reset (daily/weekly)

### Reward tidak masuk setelah claim

**Check**:

1. Check notifikasi success
2. Check XP di profile (level bar)
3. Check Coins di profile (coin balance)

**Solution**:

- Refresh profile screen
- Check transaction history
- Contact support jika masih issue
